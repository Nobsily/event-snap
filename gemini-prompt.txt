# 調べ方（必ず Google 検索を実行すること。記憶だけで答えない）
個人勢・小規模で活動している人が多いので、次の順に1人ずつ検索する。
1. 「"名前" lit.link」「"名前" linktr.ee」「"名前" potofu」で、本人のリンク集ページを探す（ここに X・YouTube・Instagram 等がまとまっていることが多い）
2. 「"名前" VTuber」「"名前" VSinger」「"名前" YouTube」で検索し、YouTube チャンネルを探す（チャンネルの概要欄からも他の SNS が分かる）
3. 名前の表記ゆれ（英字表記・カタカナ・ひらがな・スペースの有無）も試す
4. このイベント名と一緒に検索し、出演告知をしているアカウントが本人であることを確かめる
※ 検索機能が使えない状態なら、JSON を出さずに「検索できません」とだけ答える

# 調べること（各出演者）
- accounts：本人の SNS アカウント。X・Instagram・TikTok・YouTube・Twitch など、見つかったものをすべて
- hashtags：本人が「感想・ファンアート・エゴサ用」として案内しているハッシュタグ（重要な順。先頭が総合タグ）
- bio：X のプロフィール文を原文のまま（X が無ければ、主に使っている SNS のプロフィール文）
- youtube_about：YouTube チャンネルの概要欄を200字程度に要約（チャンネルが無ければ空文字）

# ルール
- name は対象リストの表記を一文字も変えずにそのまま使う（ツール側で名前を照合して補完するため）
- date・start は対象リストの値をそのまま入れる
- 推測で埋めない。確認できない項目は空文字 "" または空配列 [] のままにし、confidence を "low"、note に理由を書く
- confidence の基準：high＝本人のアカウント・公式で確認できた／medium＝状況から本人とほぼ判断できた／low＝未確認
- 同名・似た名前の別人と取り違えないよう、所属・活動内容・イベント出演の告知などで本人であることを確かめる
- ハッシュタグは先頭に半角の # を付け、全角＃・空白を含めない
- accounts の platform は x / instagram / tiktok / youtube / twitch / linkhub（lit.link 等のリンク集）/ other のいずれか。id は @ を付けないユーザー名、url はプロフィールの URL
- 対象リストの全員を出力する（見つからなかった人も、name と note を入れて出す）
- 出力は下の形式の JSON だけを、```json で始まるコードブロック1つで出す。前後に説明文を付けない
